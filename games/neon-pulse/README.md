# NEON PULSE

아이패드용 한 손가락 아케이드 로그라이트. **단일 HTML 파일 하나로 완전 오프라인 동작**한다.

## 무엇인가

- 화면 아무 곳이나 **끌어서** 이동. 공격은 가장 가까운 적을 향해 자동으로 나간다. 버튼 없음.
- 적을 죽이면 경험치가 떨어지고, 레벨업마다 **강화 3장 중 1장**을 고른다. 16종 강화가 섞이면서 매판 빌드가 달라진다.
- 20초마다 사방 러시, 42초·이후 78초마다 **센티넬(보스)** 등장. 시간이 갈수록 적 체력·속도·스폰 밀도가 함께 오른다.
- 판이 끝나면 점수에 비례해 코인이 쌓이고, 메인 화면의 **영구 강화** 5종에 쓸 수 있다.

## 오프라인으로 쓰는 법 (아이패드)

1. `index.html`을 파일 앱으로 내려받는다.
2. 파일 앱에서 탭 → Safari로 열기.
3. 공유 → **홈 화면에 추가**. 이후 비행기 모드에서도 실행된다.

네트워크가 필요한 요소는 Google Fonts 링크 하나뿐이며, 끊겨도 시스템 폰트로 정상 동작한다.
효과음은 WebAudio로 합성하므로 사운드 파일이 없다. 기록은 `localStorage`에만 저장된다
(시크릿 모드 등으로 저장이 막혀도 게임은 그대로 돌아간다).

## 구조

의존성 없는 단일 파일. `<style>` → 마크업 → `<script>` 순이고, 스크립트는
입력 / 적 정의 / 데미지 / 업데이트 / 강화 풀 / 렌더 / UI·루프 블록으로 나뉜다.
밸런스를 만지려면 `ETYPES`(적 스탯), `spawnWave()`(밀도), `UPGRADES`(강화), `PERKS`(영구 강화)만 보면 된다.

## 조작 (데스크톱 확인용)

마우스 드래그 또는 WASD / 방향키, `Esc`·`P`로 일시정지.
